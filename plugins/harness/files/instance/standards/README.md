# standards/

Local overrides of the harness standards. The harness's own standards stay where the harness keeps
them; this folder holds only where this instance differs.

Naming: give an override the same file name as the standard it changes (`ci.md` overrides the
harness's `ci.md`). Start the file with one line naming the standard it overrides and the reason,
then state only the differences. Anything not stated follows the harness standard. A rule that has
no harness counterpart gets its own descriptive file name. Delete this file once the folder has
real content.
